# Sable Front — downloads

An original Godot squad RTS prototype for landscape Android play.

## Download

- [Android APK — 55 MiB](https://github.com/jhonshepherddelsocorro-spec/Mobile-rts/raw/refs/heads/downloads/SableFront-android.apk)
- [Godot project source ZIP — 2.9 MiB](https://github.com/jhonshepherddelsocorro-spec/Mobile-rts/raw/refs/heads/downloads/SableFront-godot-source.zip)
- [SHA-256 checksums](SHA256SUMS.txt)

On Android, download the APK, open it, and allow installation from your browser or file manager if Android asks. Requires Android 7.0+ and OpenGL ES 3.0; ARM32 and ARM64 are included. This is a development-signed prototype, not a store release.

To edit the game, extract the source ZIP, import `SableFront/project.godot` in Godot 4.6.3, and run the project.

## What is playable

Controllable squads, cover and suppression, enemy AI, territory capture, connected supply routes, fluctuating commodity prices, trading, supply convoys, recruitment, touch controls, and local save/resume.

465 automated assertions passed during development. APK signature and native-library alignment verified. Physical Android device testing remains pending. Detailed controls, source and asset licenses, and validation notes are inside the source ZIP.

These are the unchanged, checksum-verified artifacts from prototype version 0.1.0.
